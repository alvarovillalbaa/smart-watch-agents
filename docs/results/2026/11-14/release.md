## Limits and next native gate

Ordinary native-window launch, an actually mounted WidgetKit widget, Developer-
ID/notarization/Gatekeeper, physical watches/push, Kotlin compilation and real
agent/production hub/TLS acceptance remain pending. A queued-command receipt
does not prove execution. The hub has single-owner pairing, not tenant roles or
read-only tokens; operator TLS/network/backup/device lifecycle controls remain
the operator's responsibility. No Chrome Web Store/App Store/npm-registry or
public Docker registry publication is claimed. Browser coverage is Chromium
with emulated touch; broad accessibility/performance/Safari/Firefox unverified.

The wider portfolio goal remains ACTIVE and unfinished. Four non-priority apps
and prior Linen/npm/Simulator/provider gates remain unchanged. This is the first
scoped Watch Agents desktop release, not completion of every portfolio project.
